# ☕🖤 Nevermore Cafe

**Nevermore Cafe** is a dark, gothic and fantasy-inspired cafe website built using **HTML and CSS**.

Instead of creating the usual bright and minimal cafe website, I wanted to experiment with something completely different — a mysterious, atmospheric design inspired by **dark academia, gothic aesthetics and the after-dark vibe of the Wednesday universe**.

The goal was not just to create a cafe webpage, but to make the website itself feel like stepping into a different atmosphere.

## ✨ About the Project

Nevermore Cafe is designed as a fictional cafe where everything revolves around a darker, more mysterious aesthetic.

From the colours and typography to the layout, images and content, I tried to keep the design consistent with the theme throughout the entire website.

The project includes multiple sections that together create a complete cafe website rather than just a landing page.

The main idea behind the design was:

> **“A darker place for better coffee.”**

I wanted the website to feel calm, mysterious and slightly unusual — something that would fit a cafe where people could sit late at night, have coffee and just disappear into their own world for a while.

## 🎨 Design System

A major part of this project was developing a consistent visual identity.

The website uses a predominantly dark colour palette with shades of:

* Black
* Dark grey
* Muted purple
* Brown
* Gold
* Off-white

Purple is used as one of the main accent colours, while muted tones help maintain the darker atmosphere.

For typography, I experimented with a combination of **serif-style headings and clean body text** to create a contrast between the mysterious theme and readability.

---

## 📱 Responsive Design

The website was also designed to work across different screen sizes.

I used CSS media queries to adjust the layout for:

* Desktop
* Tablet
* Mobile

Different sections such as the navigation, hero content, menu layouts and gallery adapt depending on the available screen width.

The gallery, for example, moves from a multi-column layout on larger screens to fewer columns on smaller devices.

This helped me get more comfortable with creating layouts that don't only work on my own screen.

## 🧠 What I Learned

The biggest lesson from this project was that **good frontend design is not only about making individual sections look good**.

Everything needs to work together.

The colours, typography, spacing, images, buttons and sections all need to communicate the same visual idea.

While working on Nevermore Cafe, I started thinking more about the **overall user experience and visual storytelling** rather than simply completing one section at a time.

I also became more comfortable writing larger CSS files and organizing styles for an entire website.

Another important thing I learned was responsive design. A layout that looks good on a desktop doesn't automatically work on mobile, so I had to think about how different sections should change as the screen becomes smaller.
